## How to use 
 
1. Click the green "< > Code" bottom.  
2. Click "Download ZIP" to download the repository to your machine.  
3. Unzip the repository and move it somewhere to your machine that you can remember.   
4. The instruction material and exercises are in the "ProblemSets" folder.  
5. The "Data"" folder contains example data files required for demonstrations and exercises.
